# 把「三策略组合（AND）」搬进同花顺 / 东方财富 / 通达信

结论：**能做，但要拆成两件事**——① 指标公式（在 K 线图上画买卖点、看三条线状态）；② 条件选股 / 条件预警（让软件替你盯盘、弹提示）。

回测净值、仓位曲线、逐笔明细这些搬不过去：软件里的公式只能"算当下"，不做资金曲线回测。

---

## 一、能力对照

| 需求 | 同花顺 PC | 通达信 | 现有云端方案 |
| --- | --- | --- | --- |
| 图上画买卖点 | ✅ 自编主图指标 | ✅ | ✅（网页版） |
| 盘中自动盯盘提醒 | ✅ 条件预警（需电脑开着） | ✅ 预警系统 | ✅ 不需要电脑 |
| 手机收提醒 | ⚠️ 需 PC 端预警在线 + 同花顺账号推送 | ⚠️ 同左 | ✅ 微信「方糖」 |
| 历史回测 / 净值曲线 | ⚠️ 有限（付费版策略回测） | ⚠️ 有限 | ✅ 完整 |
| 30 分钟口径 | ✅ 切到 30 分周期即按 30 分算 | ✅ | ✅ |

> 关键限制：**手机 App 不能自己新建公式**，公式和预警都只能在 PC 端配置。东方财富 PC 版编辑器带「同步手机测试」，可以把做好的指标同步到东财 App **只读查看**，但**不能针对自编公式设预警**；同花顺手机版连查看都得靠 PC 端预警转发。这也是当初选 GitHub Actions 的原因——不依赖你的电脑。

## 二、主图指标公式（画买卖点）

公式管理器 → 新建「技术指标」→ **画线方法选「主图叠加」**（东财里叫「主图坐标」）→ 粘贴。

### 2.1 通用兼容版（推荐，东方财富 / 同花顺 / 通达信 都能过）

只用了 `MA / EMA / REF / DRAWTEXT / STICKLINE`，都是三家共有函数：

```
MA5:MA(CLOSE,5),COLORYELLOW;
BBIV:(MA(CLOSE,3)+MA(CLOSE,6)+MA(CLOSE,12)+MA(CLOSE,24))/4,COLORMAGENTA;

DIF:=EMA(CLOSE,5)-EMA(CLOSE,10);
DEA:=EMA(DIF,5);

P1:=CLOSE>MA5;
P2:=CLOSE>BBIV;
P3:=DIF>DEA;
LONG:=P1 AND P2 AND P3;

BUY:=LONG AND REF(LONG,1)=0;
SELL:=LONG=0 AND REF(LONG,1)=1;

DRAWTEXT(BUY,LOW*0.99,'B'),COLORMAGENTA;
DRAWTEXT(SELL,HIGH*1.01,'S'),COLORYELLOW;
```

保存后「测试公式」应通过；图上会在买点 K 线下方写紫色 B、卖点上方写黄色 S。

### 2.2 想要箭头图标（仅同花顺 / 通达信，东方财富不支持）

在 2.1 基础上把两行 `DRAWTEXT` 换成（或并列）：

```
DRAWICON(BUY,LOW*0.995,1);
DRAWICON(SELL,HIGH*1.005,2);
```

**`DRAWICON` 在东方财富 PC 版里不存在**，粘进去会在该行报「缺少数字、变量、常量或函数名」——这就是最常见的报错原因，删掉即可。

### 2.3 函数支持对照

| 函数 | 东方财富 PC | 同花顺 PC / 通达信 |
| --- | --- | --- |
| `MA` `EMA` `REF` `AND` | ✅ | ✅ |
| `DRAWTEXT(COND,PRICE,'字')` | ✅ | ✅ |
| `STICKLINE(COND,P1,P2,W,0)` | ✅ | ✅ |
| `DRAWICON(COND,PRICE,TYPE)` | ❌ 报错 | ✅ TYPE 1=↑ 2=↓ |

- `MA5` 就是「价格穿越均线(5,1)」的 5 日线；`BBIV` 是 BBI(3,2) = MA3/6/12/24 的等权平均
- `LONG` 即 AND 合成：三票同时看多才持仓
- `BUY` / `SELL` 是仓位翻转点，与回测工具图上的三角一致
- 若 `DRAWTEXT` 也报错（个别老版本），就把它删掉，公式照常保存——信号本身仍由第 12/13 行的 `BUY` / `SELL` 决定，条件预警/选股都不受影响，只是图上不写字

## 三、条件选股公式（找今日新信号）

公式管理器 → 新建「条件选股」→ 粘贴：

```
{名称：三策略AND买}
MA5:=MA(C,5);
BBIV:=(MA(C,3)+MA(C,6)+MA(C,12)+MA(C,24))/4;
DIF:=EMA(C,5)-EMA(C,10);
DEA:=EMA(DIF,5);
LONG:=C>MA5 AND C>BBIV AND DIF>DEA;
XG:LONG AND REF(LONG,1)=0;
```

卖出信号把最后一行换成：

```
XG:LONG=0 AND REF(LONG,1)=1;
```

设好后：功能 → 智能选股 / 条件选股 → 选中该公式 → 执行，即可筛出当日出现信号的票。

## 四、条件预警（盘中自动提醒）

1. 工具 → 条件预警（新版叫「智能盯盘」或「预警」；东方财富在「功能 → 预警」里）
2. 新建预警 → 条件类型选「公式条件」→ 选 `三策略AND买`
3. **周期**：日线就用「日线」；要 30 分钟信号就选「30 分钟」
4. 触发方式：勾选 弹出窗口 / 声音 / 邮件 / 消息推送到手机（需登录同账号并在手机 App 开启通知）
5. 添加监控标的 588170（整板 / 自选股可批量）

> 注意：行情为**未收盘**的当前 K 线时，翻转可能反复出现又消失（信号闪烁）。回测口径是「收盘确认、次日开盘成交」，所以更稳的做法是收盘后再看，或用 30 分钟周期等这根 K 线走完。

## 五、口径一致性（重要）

我已用 180 根真实日线把「公式写法」和「网页引擎」逐根比对过：

| 项目 | 结果 |
| --- | --- |
| 组合 AND 仓位（180 根） | **完全一致，0 处差异** |
| 价格穿越均线 5 | 0 处差异 |
| BBI(3,2) | 0 处差异 |
| MACD(5,10,5) | 160 根一致；开头 20 根因 EMA 预热算法不同略有差异，之后收敛 |

注意事项：

1. **复权设置必须一致**：软件里设为**前复权**（与监控的 `fq=1` 对齐），否则长周期的均线位置会漂。
2. EMA 预热：软件的 EMA 从第一根数据递推，网页用前 N 根均值起算，历史头 20 根左右会有细微差别，不影响近期信号。**看盘时数据区间别拉太短**，BBI 需要 24 根以上才有值。
3. `C = MA` 的极端边界：网页用状态机保留上一根仓位，公式按 `>` 判定为不满足。价格恰好等于均线的概率极低，可忽略。
4. 改参数要三处同步：`MA5` 的 5、`BBIV` 里的 3/6/12/24（= 3×1/2/4/8）、`EMA(...5)` 与 `EMA(...10)` 与 `DEA:EMA(DIF,5)`。漏改一处口径就变了。

## 六、建议用法

- **同花顺负责"看"**：装主图指标，盘中打开就能看到三条线的相对位置和箭头，比网页方便。
- **云端负责"提醒"**：真正要"人不在电脑前也能收到信号"，还是用现在的 GitHub Actions + 方糖——电脑关机、换电脑、睡觉都不影响。
- 两边参数保持同一套（MA5 / BBI 3,2 / MACD 5,10,5 / AND），改一处就同步另一处。
