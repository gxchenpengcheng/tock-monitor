交易明细

口径说明：年化按 252 个交易日折算；夏普 = (日均收益 × 252 − 无风险利率) / 年化波动；索提诺用下行波动；卡玛 = 年化收益 / |最大回撤|；最大回撤基于每日收盘净值。交易为「收盘出信号 → 次日开盘成交」，买入价含正向滑点、卖出价含负向滑点。
数据来源：「模拟行情」为可复现的随机生成数据，仅用于验证工具与策略逻辑；「A股 / ETF / 板块」在浏览器端直连腾讯财经公开日线接口（web.ifzq.gtimg.cn，服务端开放 CORS），失败时自动回退东方财富 JSONP 接口，两者都不可达时可改用 CSV 上传。支持沪深股票、科创板、创业板、ETF/LOF 与主要指数，默认前复权，单次最多 640 根日线。盘中抓到的是当日未收盘日线，前复权数据会随最新除权而变化，价格 ≤ 0 的记录会被自动剔除。
板块指数：行业板块（881xxx，如半导体 881121）、概念板块（885xxx / 886xxx，如人形机器人 886069）取自同花顺 v6/line 行情脚本，可直接输代码或板块名（支持「半导体」「光伏」这类模糊匹配）。板块指数是等权/加权点位，没有复权概念，回测的「持仓手数」对指数只作模拟，收益与回撤口径与个股一致。板块分钟线同样来自同花顺（30 分钟最多 140 根）。走势图的「30分」页签按需拉取：个股走腾讯分钟线接口（mkline，最近 320 根），板块走同花顺，分钟线均不支持复权、仅用于图表展示，回测口径仍为日线。
多策略叠加：组合模式对各策略「当日收盘后的目标仓位」做逻辑合成（全部同意 / 多数同意 / 任一同意），再用同一份资金、同一套费用口径回测；各策略独立净值只是对照，不代表分散投资或多标的组合。合成时可以叠加同一策略的不同参数。
风险提示：历史回测不代表未来收益，回测未考虑涨跌停无法成交、停牌、流动性冲击与分红再投资；本工具不构成任何投资建议。
